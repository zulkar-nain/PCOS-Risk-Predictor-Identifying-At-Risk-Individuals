# PCOS-Risk-Predictor-Identifying-At-Risk-Individuals
This project aims to detect the at risk PCOS patients for better healthcare service and load balancing for healthcare professionals. Patients at high risk after doing the tests can be given extra care and can be sent to their desired doctors before the low risk patients for assessment.


This project was completed by Zulkar Nain and Syeda Lamima Islam for our Artificial Intillegence Course project at undergraduation.
